# 功能测试

要求 Node.js 22.19+，安装后在仓库根目录执行。

```powershell
npm ci --ignore-scripts
$env:PI_OFFLINE = '1'
$env:NODE_OPTIONS = '--max-old-space-size=384 --max-semi-space-size=4'
npm test
```

## 可选集成环境

完整容器验证需要可运行的 Linux Docker 引擎和已有镜像。

```powershell
docker pull ubuntu:22.04
$env:REDMAPLE_SANDBOX_IMAGE = 'ubuntu:22.04'
npm test
```

PaperPilot 领域适配提供独立 HTTP 协议测试。实际宿主集成另需 PaperPilot 源码、Python 依赖和 scholar-apprentice 环境。指定宿主根目录后运行同一套测试。

```powershell
$env:REDMAPLE_PAPERPILOT_ROOT = 'F:\path\to\paperpilot'
npm test
```

缺少 Docker 镜像配置或外部宿主时，对应集成用例显示 skipped。显式指定的宿主路径无效会导致测试失败。独立检出可以执行协议、运行时、存储、知识、经验和恢复测试。
